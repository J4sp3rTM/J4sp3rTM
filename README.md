## Jakob

Developer and IT specialist, remote from Germany. My work covers front ends, small desktop tools, and automation scripts.

Send me a collaboration idea, a tool problem, or a project request. You get a direct answer to every message. The website [j4sp3r.dev](https://j4sp3r.dev) shows four ways to contact me.

## Projects

- **[DMA-Mouse-Control](https://github.com/J4sp3rTM/DMA-Mouse-Control)** (C++). Controls a mouse externally through DMA. The API is simple and needs no configuration. Use it for game development, automation, and research.
- **[PEAnalyzer](https://github.com/J4sp3rTM/PEAnalyzer)** (C#). Reads PE (Portable Executable) files from the Windows command line. Prints headers, sections, imports, exports, and export forwarders. Writes optional JSON output for scripts and PowerShell pipelines.
- **[todo-manager](https://github.com/J4sp3rTM/todo-manager)** (Kotlin). Tracks TODO comments in JetBrains IDEs. Shows them in a tool window and highlights them inline.
